# 分离本地监听与局域网监听

后续修订：监听认证的持久化与读取失败重置方向见 [ADR-0042](0042-encrypt-proxy-listening-configuration.md)；该修订已实施。

**状态**：已接受。

2026-10-13 修订：局域网启用状态与监听模式独立。

现有单组监听将本机使用与网络设备共享耦合在同一对端口上。改为始终提供本地入口，并允许独立开启局域网入口，使局域网的地址族、身份验证和 UDP 开关不改变本机入口。

## 已确认的决策

- 后台代理客户端运行时，本地 SOCKS 与 HTTP 始终在 `127.0.0.1` 监听；不增加本地监听开关。
- 本地默认端口为 SOCKS `11086`、HTTP `11087`；本地 SOCKS 固定 `tcp_and_udp`，HTTP 固定 `tcp_only`。
- 局域网默认端口为 SOCKS `11088`、HTTP `11089`；启用状态为独立 Bool 开关，默认关闭。
- 局域网监听模式为所有 IPv4 接口、所有 IPv4 与 IPv6 接口、所有 IPv6 接口，默认所有 IPv4 接口。三项分别绑定 `0.0.0.0`、`::` 配合 `ipv6_only=false`、`::` 配合 `ipv6_only=true`。关闭不覆盖已选监听模式，重新启用沿用所保存的模式。
- 四个端口限制为 `1025...65535`，且全部互异；关闭局域网监听时也校验这些配置约束。
- 局域网 SOCKS UDP 默认关闭，用户可以开启；表单说明身份验证无法可靠保护 UDP 中继。
- 仅检查 TCP 端口占用。局域网关闭时不检查其端口占用。配置不显式指定 UDP 端口，使用 sslocal 的默认行为。
- 局域网 SOCKS 与 HTTP 共用一组用户名和密码；身份验证默认关闭。
- 首次编辑预填用户名 `user`，并生成 10 位小写字母和数字密码。未保存的密码随取消操作丢弃；保存后不重新生成。
- 用户名和密码均为 1–255 字节的可打印 ASCII；用户名不得包含 `:`；不自动删除首尾空格。
- 身份验证关闭时保留凭据，并禁用凭据输入框。局域网关闭时保留全部配置，并禁用监听方式、端口、UDP、身份验证与凭据控件；取消与保存仍按原有规则可用。
- 密码保存在现有 Keychain 凭据存储中。保存失败保留旧配置；复制命令时读取失败停止复制并显示错误。运行时认证文件仅允许当前用户读写，配置摘要不包含密码。wrapper 隐藏上游认证失败日志中客户端提交的密码；超长日志丢弃到下一个换行，防止分块输入泄露尾部。
- 设置使用“本地监听”和“局域网监听”两个入口，每项独立 sheet；每个 sheet 的完整值独立保存。
- 局域网 sheet 切换启用开关只修改草稿；保存成功后才改变实际监听。关闭草稿时保留本次尚未保存的所有修改，重新启用恢复编辑并重新检查 TCP 端口占用；过期探测结果不能影响保存。取消丢弃本次全部修改。
- 外层局域网设置项始终显示已保存的状态；关闭时只显示“关闭”，不显示监听方式、端口、UDP 或身份验证详情。
- 界面使用 `SOCKS`、`HTTP 代理端口`、`所有 IPv6 接口`。
- 首页默认命令地址为 `127.0.0.1`，使用本地端口且不加入凭据。其他候选来自现有 Wi-Fi/Ethernet 地址策略，按局域网模式过滤；选择这些地址时使用局域网端口，必要时加入凭据。
- 局域网关闭时不提供局域网命令地址候选，原局域网地址选择回退 `127.0.0.1`，不执行局域网防火墙观察；所保留的监听模式不影响有效本地入口。
- 首页移除 `::1` 候选。地址失效时回退 `127.0.0.1`；选择仍仅属于当前会话。
- URL 特殊字符编码后再生成 shell 命令；tooltip 与复制内容都包含完整命令和真实密码。
- NG2 尚未正式发版，不迁移旧监听配置，新安装使用默认值；本次独立启用开关调整不要求兼容旧局域网记录。

## Module 设计

- 扩展现有监听 Module：`SslocalListenSettings` 包含本地与局域网的明确类型；负责四端口校验和有效入口派生，不引入任意数量的通用监听数组模型。
- 复用 `SettingsWorkflow` 的独立编辑与保存 Interface。认证文件格式和凭据提交留在现有持久化与运行配置 Implementation 内，UI 不拼接运行时 JSON。
- 从单组监听改为本地与局域网独立监听时，旧监听字段与旧监听文件不再作为新监听的输入；其他偏好与服务器资料保留。
- 系统代理、健康检查的本机目标、菜单 HTTP 环境命令始终使用本地入口；运行时同时检查所有启用入口是否建立 TCP 监听。
- 保存成功后，运行中的后台代理客户端按需重启；关闭状态下保存不启动客户端。运行失败不回滚保存的配置，代理状态界面报告失败。

## 与已有决策的关系

本决策取代 ADR-0015 的单组监听设计；ADR-0008 的固定 UDP 约束保留在本地监听；ADR-0013 的独立保存原则保留，但端口范围改为 `1025...65535`。历史 ADR 正文不作语言迁移。

## 上游默认行为

sslocal v1.26.0 未设置独立 UDP 地址与端口时，SOCKS UDP 中继沿用该入口的地址与端口，并非每次 UDP ASSOCIATE 随机分配中继监听端口。本设计不设置独立 UDP 端口，也不增加 UDP 占用检查。[默认地址派生](https://github.com/qiuyuzhou/shadowsocks-rust/blob/v1.26.0/crates/shadowsocks-service/src/local/socks/server/mod.rs#L121)、[UDP ASSOCIATE 回复](https://github.com/qiuyuzhou/shadowsocks-rust/blob/v1.26.0/crates/shadowsocks-service/src/local/socks/server/socks5/tcprelay.rs#L301)。
