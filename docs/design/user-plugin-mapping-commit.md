## 已定范围

保留 `PluginCatalog` 为映射提交 module，通过其 `commit` interface 验证验证、原子保存、发布、重校验与后续运行收敛。目录工作流和运行控制器作为集成观察面，不新增提交框架或进程启动 adapter。

- 保存失败不得改变已提交映射、代次或目录投影，也不得触发运行应用。
- 运行应用失败不得撤销保存；重建目录后仍恢复用户保存的映射。
- 连续 A→B 保存以 B 为最终意图；尚未开始的旧任务不得应用 A，已在运行的旧任务不得覆盖 B 的最终运行状态或契约。
- 映射变化立即重校验配置组成员；无效成员不参与运行，仍有有效成员时保留活动组目标。
- 无关映射变化与相同映射提交不得重启健康且契约一致的代理。
- 同一快照指同一已提交映射代次；文件可用性在每次激活或运行派生时重新检查。

只修复回归揭示的问题。不增加文件监听、文件替换自动重启、逐次映射保存的应用结果记录或管理 UI。运行失败继续由既有控制器状态呈现。
