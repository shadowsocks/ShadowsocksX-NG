# 规则方案统一决定自定义规则行动

**状态**：已接受，已实现（2026-10-30）。

## 决定与原因

产品术语统一为“规则方案”，替代“规则预设”。每项方案固定定义匹配后行动与未匹配行动；内置规则和自定义规则的匹配后行动由所属方案统一决定。固定本地目标仍始终直连，不受方案行动影响。

| 规则方案 | 匹配后行动 | 未匹配行动 |
| --- | --- | --- |
| 仅GFW列表内目标代理 | 代理 | 直连 |
| 中国大陆目标直连 | 直连 | 代理 |
| 中国大陆目标代理 | 代理 | 直连 |

新增和编辑自定义规则只允许编辑匹配类型与匹配内容，行动以只读说明呈现。预览、保存、加载、离线测试和运行配置生成均遵守所属方案的行动约束，不能仅通过隐藏表单控件实现。各方案仍独立拥有自定义规则集合，查看或编辑方案不切换实际路由。

这一约束有意收紧上游 ACL 能力，降低用户理解成本。项目固定使用的 [sslocal v1.26.0](https://github.com/qiuyuzhou/shadowsocks-rust/blob/v1.26.0/crates/shadowsocks-service/src/acl/mod.rs) 对 IP 字面地址先检查直连列表，再检查代理列表，最后采用模式默认行动；未命中域名规则而检查 DNS 解析结果时，则按模式选择一个方向的 IP 列表。允许每条自定义规则独立选择行动，会把这些差异带入用户模型。产品选择统一的方案语义，不要求用户理解这些差异。

## 迁移与兼容边界

迁移现有各方案的自定义规则集合：移除行动与该方案未匹配行动相同的自定义规则，保留行动与匹配后行动一致的条目及其 UUID、匹配条件和相对顺序。被移除条目不翻转行动，也不迁往其他方案。schema 1–3 文档在读取时迁移，不重写原文件，下次正常原子保存写入 schema 4；schema 4 文档中的反向行动视为无效并拒载。旧客户端拒绝 schema 4，避免降级后重新写入反向行动。

该迁移不承诺保持所有旧流量行为。例如“中国大陆目标代理”方案中，自定义直连 IP 规则可以优先于覆盖该 IP 的内置代理规则；移除后，直接访问该 IP 可能从直连变为代理。接受旧反向例外失效，以换取规则方案对 IP 与域名一致的用户语义。发布说明应说明移除规则及可能的路由变化。

规则身份仍按匹配条件与行动共同确定。规则停用仍作用于方案内跨来源的规则身份；沿用现有孤立停用记录保留原则，删除自定义条目不隐式清除其停用记录，也不改变其他身份的启用状态。固定本地保护及损坏文件不覆盖原则保持有效。

本决定取代 [ADR-0051](0051-explicit-rule-preset-modeling.md) 中“自定义规则保留自身行动”的约定，以及旧自定义文档直接保留反向行动的加载行为；其他方案归属、规则身份和停用语义保持有效。
