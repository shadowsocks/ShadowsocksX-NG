# sslocal 配置单向输出与运行意图比较

**状态**：已接受（2026-10-19）。

GUI 的内存运行意图与 sslocal JSON 输出分离。上游配置只包含上游字段，移除 `x_shadowsocksx_ng_acl` 和 `x_shadowsocksx_ng_listen`。GUI 不再解码该配置恢复派生输入、认证资料或诊断事实；不新增完整运行意图的持久副本。

模式切换与规则保存共用从最新已保存目录、活动目标、监听配置及插件资料重新派生的路径。选择这一方式是为了减少快照状态与派生分支，不为极端并发场景增加恢复机制。目录或监听配置不可读时，继续遵循 ADR-0035、ADR-0042 的运行阻断与已有后台服务保留规则。

运行发布 module 统一拥有意图比较、认证文件复用与文件准备。GUI 私有的同代 `intent.json` 保存意图摘要、最终配置字节摘要和脱敏诊断摘要，不保存完整配置或凭据。意图摘要用于等价判断和失败意图识别；最终字节摘要只用于检查输出文件漂移；随机部署身份继续关联 Agent 操作、回执与失败记录。三者不互相替代。GUI 可以读取输出字节计算摘要，但不解析其 JSON。私有意图摘要不进入监管资料、回执或诊断。

LAN 认证仍写入现有受保护的明文认证文件。发布 implementation 比较本次内存生成的字节与当前监管资料引用的认证文件，相同则复用文件与随机认证身份，不同或不可读则重新准备。此比较不读取 sslocal 配置，也不增加凭据摘要、版本状态或完整秘密快照。未来认证文件是否加密仍开放；若编码形态变化，在发布 implementation 内调整比较方式，不提前引入通用加密框架。

本决定补充 ADR-0038，沿用其代次、锁、不可变发布、稳定链接、ACL 复用与清理规则，以及 ADR-0037 的失败处理。本次不实施加密、密钥交接、sslocal 应用确认协议或文件引用格式改造。当前回执仍不表示 sslocal 已确认应用重载。
