# 用户插件表单目录事实

2026-10-05 候选 2 的已确认实施范围，基线 `128efcc`。本文记录本次任务规格，不代表持续维护的项目现状。

- 表单只接收目录派生的名称、来源和可用性事实，不依赖 managed 发布清单、不保留兼容回退，不携带本机可执行文件路径。
- 来源不参与服务器引用身份，不增加来源标签，用户覆盖不继承托管版本信息。
- 新建、编辑和订阅只读表单都根据当前所选名称展示缺文件、不可执行、文件检查失败或映射读取失败的提示；不可用映射仍可保存服务器引用，激活校验负责阻断。
- 未解析引用和已保存参数沿用现行保留规则；映射新增、删除或同名覆盖切换不得覆盖未保存参数和其他服务器字段。
- 非敏感 presentation 保留完整目录事实，但参数明文为空。
- 未解析引用提示采用：未找到插件“%@”。引用和已保存参数将保留；可添加同名用户插件，或改选其他插件或“无”。
- 文件缺失提示采用：插件文件不存在，请检查用户插件路径或应用安装。
- 不可执行提示采用：插件文件不可执行，请检查文件类型和执行权限。
- 文件检查失败提示采用：无法读取插件文件信息，请检查路径和访问权限。
- 映射读取失败提示采用：无法读取用户插件映射，插件暂不可用。请修复映射后重试。
- 对应英文采用本次对话已批准的五组文案，维护于 Localizable.xcstrings。
- 验证 seam 为 CatalogWorkflow 的新建/编辑/展示 interface 及 ServerFormFields 的装载、草稿编辑与展示刷新 interface。
- 本轮不实现插件管理 UI、来源标签或系统安全检查提示展示。
