# 分离 Agent 监管资料与 sslocal 输入

**Status**：accepted（2026-10-19）。已实施；验证结果见对应实现提交。

后续修订：GUI 与上游配置的单向输出及私有意图比较见 [ADR-0043](0043-one-way-sslocal-configuration-output.md)。

## 职责

GUI 派生并写入 sslocal 配置、LAN 认证文件和 ACL 文件，再原子替换独立的非秘密监管资料。Agent 只解码监管资料，不再从 sslocal 配置读取服务器列表或 LAN 凭据，也不再生成认证文件。本次为后续 age 加密准备职责分离，不引入 age、Agent 密钥或 sslocal 解密能力。

监管资料描述部署身份、探测端点、重启判定所需的非秘密身份、具体文件引用和各 ACL 变体的保留引用。不得包含服务器密码、完整插件参数、LAN 用户名或密码，以及凭据引用；不得复制包含认证秘密的现有监听指纹，或用低熵凭据的无盐摘要充当公开身份。

## 发布与运行

配置按部署生成不同文件名，发布后保持不变。认证和 ACL 文件只在内容变化时新建；未变内容复用已有文件，切换模式不重写大型规则 ACL。监管资料的原子替换是部署意图的发布点，不代表 sslocal 已应用该部署。

Agent 独占运行目录内共享稳定配置链接和 `acl-active.ini` 的切换权。sslocal 以稳定配置链接路径启动，配置中的 ACL 路径始终指向稳定 ACL 链接。仅服务器变化时，Agent 切换配置链接并发送 SIGUSR1。当前固定版本的 ACL 变化继续完整重启；升级至支持 SIGUSR2 的版本后，另行核实并接入 ACL 热重载。

监听、认证或当前版本的 ACL 变化要求重启。Agent 必须停止旧子进程、确认其退出、切换链接，再启动新子进程，不安排新旧子进程重叠运行。链接目标必须是运行目录内的受管文件，保留路径防逃逸和过期准备结果保护。

两个链接分别原子切换，不承诺配置与 ACL 同时生效。现有 SIGUSR1 回执也不能证明 sslocal 已完成配置应用；本次不将信号投递成功解释为上游应用确认。

## 代次与清理

以持久、单调递增的 UInt64 整数代次标识部署，文件名使用固定宽度十进制字符串；不依赖文件时间戳或时钟顺序。GUI 分配代次并串行发布，新代发布后不得发布过期准备结果，回收的文件名不得复用。高水位保存在 `runtime-generation`，预留允许留空号，损坏或溢出时拒绝发布，停止服务不删除高水位。

Agent 在完成切换后清理旧文件。以同一份监管资料内的代次和引用判断保留集合；未来代次及当前代次不清理，旧代文件仅在没有保留引用时清理。保留当前部署、当前子进程仍使用的文件，以及各 ACL 变体的最新文件。不能仅因文件代次较旧就删除复用的 ACL 或认证文件。

GUI 不得重新引用退出保留集合的旧文件；准备文件必须先获得新代次保护。GUI 清理本次取消或失败的未发布文件。清理过程必须覆盖并发发布，不得删除下一代正在准备或已发布的文件。GUI 准备、分配和发布，以及 Agent 的扫描、最新引用合并和删除，共享运行目录中的 `runtime.lock`（flock）。GUI 只从锁内读取的已发布保留集合复用文件。Agent 清理同时保护自身快照、子进程使用过的引用和锁内读取的最新发布引用。旧快照清理不能与 GUI 复用已退休文件交错；GUI 准备文件的代次始终高于 Agent 清理边界。单一 Agent 在运行期还持有 `agent.lock`，避免并发启动。

配置、认证和 ACL 文件名均包含 20 位十进制代次。认证身份使用随机 UUID；只在凭据变化时换身份和文件，不公开凭据摘要。GUI 为每份配置准备同代 `config-<generation>-intent.json`，保存 GUI 私有意图摘要、最终配置字节摘要与脱敏汇总，用于配置损坏后仍能识别失败意图并独立提供诊断事实；Agent 只保留该引用，不读取正文。该 GUI 私有摘要不进入监管资料、回执或诊断。

`sslocal.pid` 保留尚未确认退出的子进程身份；Agent 崩溃后若该 PID 仍存在，则拒绝启动第二个实例并报告失败。无法确认退出的进程和保守 PID 复用阻断需要用户检查并显式重试。没有可靠活跃准备者证据时，崩溃遗留的未来代文件暂不回收。

## 失败与验证

采用 ADR-0037：发布前失败不替换监管资料；发布后确认部署失败则停止子进程、暂停系统代理并保留最新意图与失败记录，不自动恢复旧部署。只允许显式重试或新运行意图再次部署；健康运行后的意外退出重放当前部署。

本决定部分替代 ADR-0011 的固定可覆写 ACL 变体及 GUI 切换活动链接方式，保留按变体复用、未变内容免写、稳定 ACL 入口和 Agent 不读 ACL 正文。

验证范围为定向行为测试、完整 hostless 测试、Debug 构建及真实 sslocal smoke：覆盖监管资料无秘密、稳定链接服务器热重载、ACL 文件复用、重启端口交接、并发发布与清理、发布失败、失败记录跨重启保留及崩溃恢复。SIGUSR2 和 age 不属于此次验证范围，真实系统代理与原生界面验收不得由 hostless 或 smoke 结果替代。
