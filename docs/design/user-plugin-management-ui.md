# 用户插件管理 UI（2026-10-05）

本文件记录本轮已确认规格，现状以代码为准。

- 设置视图底部新增“插件”区域，统一展示内置与用户插件；同名覆盖占一行，区分内置、用户添加、用户覆盖。
- 行展示名称、来源、单行中间截断路径（悬停完整内容）及异常；直接提供覆盖、编辑、删除或恢复内置按钮，无只有删除的更多菜单。
- 新增、编辑和覆盖使用 sheet。新增名称/路径为空；编辑名称只读、路径预填；覆盖名称只读、路径为空。选择文件仅填路径。
- 字段为插件名称 / Plugin name、可执行文件路径 / Executable path；按钮选择文件… / Choose File…、取消 / Cancel、保存 / Save。
- 不支持改名。空名称、用户重名、非绝对路径在字段旁提示；保存重新检查文件存在且可执行。同名内置允许覆盖并提示。
- 保存失败保留 sheet 与草稿；写入成功关闭。运行时异步应用，失败不回滚映射，沿用运行时错误入口。
- 取消/Escape 直接丢弃草稿，再次打开读取已保存值。
- 删除与恢复内置都需确认；说明服务器配置保留，删除可能令原名称不可用，恢复后使用内置插件。
- 安全提示给出隔离、签名、策略的具体证据，允许展开详情；不声称能保证是否允许运行、不阻止保存、不自动解除隔离。检查无法判定时明确提示。
- 映射读取失败隐藏列表与修改按钮，展示错误与重试读取。重试仅读取配置，不整体重置。
- 进入设置、设置可见时应用重新激活、保存/删除后刷新文件可用性及安全事实；另提供刷新按钮。不添加文件监听。
- 复用组合根现有 PluginCatalog，不另建持久化目录实例。
