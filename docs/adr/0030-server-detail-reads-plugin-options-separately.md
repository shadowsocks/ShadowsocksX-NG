# 服务器详情与编辑凭据装载分离

Status: Accepted (2026-10-06).

后续决定：[ADR-0035](0035-encrypt-persistent-server-library.md) 接受持久服务器库整体解密并在应用进程内保留明文至退出，调整本文的密码按需装载与参数会话保留边界。详情不显示密码、编辑草稿与详情展示分离的要求继续有效。

服务器详情展示已保存连接资料和插件参数，不展示或读取密码；完整编辑草稿只在编辑 sheet 中装载。详情通过独立的参数读取 interface 获取插件参数，读取失败仅影响参数区。这使密码不可读时普通资料仍可浏览，也避免详情为展示参数而依赖完整编辑草稿。

插件参数仍属于敏感信息，但用户明确选择在只读详情中直接查看，以支持订阅服务器及未知插件的参数核对。参数明文仅在详情会话中持有，不加入非秘密展示投影或持久快照。相较于只显示“已配置”，这里接受主动浏览详情时读取参数的取舍；相较于复用编辑装载，这里保留密码与参数各自独立的读取范围和失败处理。

ADR-0028 的密码自动填充关闭策略继续适用于新建与编辑 sheet 中共用的密码输入字段；原有详情页表单被只读呈现替代。
