# 服务器分享 popover（2026-10-05）

本文件记录本轮用户确认的规格。替代前一轮分享 sheet 的呈现设计；当前实现以代码为准。

## 已确认决策

- 点击服务器分区工具栏「分享」，在按钮旁打开原生 popover。移除「完成」按钮，点击外部或按 Esc 关闭；切换选中服务器时立即关闭。
- 顶部依次显示已保存的服务器名称、地址与端口、加密方式、可选插件程序名。无插件时隐藏插件行；名称和地址单行显示、尾部截断。不显示密码或插件参数。
- 打开时冻结顶部资料、分享 URI 和保存面板建议文件名；不读取编辑中的未保存草稿。
- 布局为资料、分隔线、二维码、分隔线、三个操作。二维码保持 280×280 和白底衬底。
- 操作采用系统分享菜单式左对齐整行按钮，悬停显示圆角底色，顺序为「保存二维码图片」（square.and.arrow.down）、「拷贝二维码图片」（doc.on.doc）、「拷贝 URI 链接」（link）。
- 两个拷贝操作成功后保留约 2 秒「已复制」反馈；保存继续使用系统保存面板。图片未就绪时禁用图片操作；链接可直接拷贝。
- 分享入口的可用性、二维码生成、图片剪贴板格式、PNG 保存和失败提示继续沿用现有行为。

## 实现边界

CatalogWorkflow 提供不包含秘密的 ServerSharePresentation 查询。ServersView 在显式分享命令中捕获资料和 URI；ShareServerPopover 自持二维码与反馈状态。平台效果继续经过 ImageClipboard、TextClipboard 和 QrImageSaver。

现有 GLOSSARY「服务器分享」定义适用，无新增领域术语。这是可逆的 UI 呈现调整，不新增 ADR。
