# 收藏按节点身份保存独立顺序

Status: Accepted (2026-10-09)

收藏是用户对配置目录节点的独立选择，支持手动与订阅来源的服务器配置和配置组。收藏以节点身份组成的去重有序序列保存，不复制节点资料、不展开组的后代、不改变目录位置。收藏顺序独立于目录顺序；新收藏以及取消后重新添加的收藏追加到末尾。改名和移动保留收藏，复制和导入产生的新节点不继承收藏。

收藏序列与目录、订阅记录保存于同一目录文档，节点删除和失效收藏清理作为一次原子保存。订阅刷新后仍存在的节点保留收藏；消失节点的收藏立即清除，同身份再次出现不恢复收藏。相比单独保存偏好或保留失效引用，该选择省去跨文件一致性和墓碑状态，但不提供远端节点短暂消失后的自动恢复。

收藏命令集中在现有 `CatalogWorkflow`，持久化成功后发布新状态；失败保持原状态并显示错误。仅改变收藏或收藏顺序不得触发运行状态收敛，也不得更新节点时间戳。目录内容变化仍遵循现有提交与运行状态收敛规则。收藏不是配置组成员变更，不能借用目录移动或目录排序命令表达。
