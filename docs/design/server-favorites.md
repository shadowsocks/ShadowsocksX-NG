# 服务器收藏

日期：2026-10-09。状态：设计与实施范围已确认，实现与验证见本次提交。

本文记录本次任务的需求与验收条件，不代表代码当前具备这些能力。领域术语见根目录 `GLOSSARY.md`；持久化决定见 ADR-0032。

## 列表与入口

- 入口位于服务器页面内部边栏首位，顺序为「收藏／本地／订阅」。现有初始「本地」选择保持不变。
- 收藏列表使用平面 Table，仅有「名称」「路径」两列，无层级展开、列排序或排序工具栏入口。
- 名称显示当前节点自身名称；配置组显示组名。名称列沿用节点类型、有效性与活动目标的现有呈现。
- 路径使用 `/` 分隔，包含「本地／订阅」来源名称、全部祖先和节点自身名称，例如 `订阅/机场/香港/HK01`。
- 名称中的 `/` 原样显示，不转义。改名或移动后路径随目录更新；截断时悬停显示完整路径。
- 每个节点最多出现一次；收藏配置组仅增加该组一行，不自动收藏或展示后代。父组与后代可以分别收藏。
- 新收藏追加至末尾；取消后重新收藏也追加至末尾。收藏与顺序跨应用重启保留。
- 列表拖动只改变收藏顺序，不改变配置目录的位置或顺序。拒绝目录移动语义和外部拖入。

## 选择与命令

- 选择收藏行留在收藏列表，右侧复用原节点详情。配置组通过现有「激活」按钮激活。
- 详情增加「收藏／取消收藏」按钮；英文为 `Favorite / Unfavorite`。
- 「本地／订阅」列表在「名称」与「创建时间」之间增加「收藏」列；该列无排序，使用 `star.fill` 与 `star` 显示状态，仅展示、不响应点击。
- 当前收藏取消后，清除选择与详情，不自动选择相邻行；删除或订阅刷新导致选中节点消失时同样清除选择。
- 收藏行保留原节点右键菜单与资格限制。收藏列表隐藏「排序」「新建服务器」「新建分组」工具栏项，其余已有节点命令保持现有行为。
- 「分享」按当前节点提供；全局「导入」入口保留。导入成功产生节点后切换到「本地」并选中新节点，新节点不自动收藏。现有复制或新建回调同样切换至「本地」并选择新节点。
- 失效服务器与空组可以收藏；收藏不改变激活资格。侧栏切换继续清除节点选择。

## 保存与验收

- 用节点身份保存收藏顺序，不持久化派生名称、路径或凭据。
- 目录文档升级到 v6，兼容读取 v1–v5，历史文档默认为空收藏；写入使用 v6。
- 删除节点、移除订阅及订阅刷新消失节点时，同次保存清除失效收藏。刷新失败保留原目录及收藏。
- 收藏变化不触发代理运行状态收敛，不改变节点创建或修改时间。保存失败保持此前列表和顺序，并显示错误。
- 通过公共命令验证收藏唯一性、追加与重排、保存失败、重启恢复、旧文档兼容、订阅身份延续及消失、递归清理、不继承收藏、无运行状态收敛与时间戳变化。
- 用原生应用验证平面 Table、列位置、详情按钮、选择清理、拖动落点、路径悬停和工具栏。自动测试与原生界面证据分别汇报。
