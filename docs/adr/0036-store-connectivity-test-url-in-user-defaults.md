# 测试 URL 作为非敏感偏好存入 UserDefaults

Status: Accepted（2026-10-18，用户已通过 implement 指令确认实施）。

测试 URL 是非敏感偏好，以明文存入 UserDefaults，不再通过 Keychain 和代理设置中的凭据引用保存。展示、日志、诊断报告及其他路径均不要求对测试 URL 脱敏，包括其路径与查询参数；这修订 ADR-0006 对 URL 的一概排除规则，仅限测试 URL。订阅 URL、服务器密码及其他凭据的保护边界保持不变。ADR-0035 对测试 URL 的范围外凭据描述由本决定替代。

不迁移已有自定义值，不访问或清理对应旧 Keychain 项，移除旧测试 URL 引用的使用。没有新偏好时使用默认值 `http://www.gstatic.com/generate_204`；旧 Keychain 条目可能残留，不再影响测试功能。

UserDefaults 键缺失、类型错误或保存的字符串不符合现有 URL 校验时，统一使用默认 URL。保存时保留现有校验：仅允许 HTTP，要求非空主机，禁止用户名、密码与 fragment，显式端口须在 1…65535 范围内，允许路径与查询参数。合法值按项目现有 UserDefaults 方式保存并立即生效，不承诺原文件保存路径的落盘错误报告与回滚保证。

URL 变化后沿用现有行为：清空历史测试结果并取消正在执行的测试，不重启代理。界面布局、测试协议、测量算法及其他设置的存储不在本次调整范围内。

实施验收覆盖独立 UserDefaults 测试域中的自定义值往返、默认值与异常值处理、无效输入拒绝、旧引用被忽略且不访问 Keychain，以及 URL 变化的发布行为。核查测试 URL 相关脱敏规则与诊断输出，使其符合非敏感分类，同时保持其他凭据的保护。
