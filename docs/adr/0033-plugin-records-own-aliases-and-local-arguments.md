# 插件记录拥有别名与本地启动参数

插件记录以名称集合、可执行程序选择与有序本地启动参数表达同一个插件版本。服务器继续保存原始引用名称；名称精确区分大小写，不解析版本后缀、不探测二进制版本。无版本名称指向最新大版本是记录维护者的显式选择，带版本名称用于固定大版本。这样同一版本的多个引用共享本机配置，而目录解析 module 集中承担名称归属与程序选择。

用户记录具有独立持久身份，可编辑名称集合。不同用户记录禁止重名；用户只覆盖明确声明的内置名称，失效覆盖不回退内置程序。删除或移动名称不改写服务器和订阅引用。无版本名称通过先从旧记录删除并保存、再加入新记录并保存转移，接受中间暂时不可解析，以免增加专门的跨记录转移流程。

内置记录的固定身份、引用名称与打包文件名分开维护。现有 v2ray-plugin v1.3.2 同时提供 `v2ray-plugin` 与 `v2ray-plugin-v1`，仍使用原二进制。内置名称由应用发布维护；本机可以只设置或清空内置记录的启动参数，不必覆盖路径。仍使用内置记录的名称共享这些参数，被用户覆盖的名称使用用户记录自己的参数。

本地启动参数按普通配置保存，不额外接入凭据存储或增加敏感信息处理。每项是一个完整 argument，保留顺序、空格与空字符串，不执行 shell 解析，拒绝无法传给进程的 NUL。运行配置生成时写入 `plugin_args`，与服务器 `plugin_opts` 独立；本地路径和启动参数不进入服务器分享、导出或订阅资料。

`plugins.json` v1 的每项迁移为独立用户记录，保留名称和路径，启动参数为空，不因路径相同而合并；后续保存为 v2。读取失败继续阻止修改，不自动清空。保存成功才发布目录快照并启动异步运行状态收敛，失败不发布，运行失败不撤销已保存配置。单服务器不可用时拒绝激活，组内跳过不可用服务器。

设置列表按记录显示全部名称、路径、来源与可用性，内置记录标记被覆盖的名称。编辑器以列表编辑用户名称与启动参数，参数可调整顺序；服务器选择器显示每个可引用名称并保存所选原文。删除用户记录删除其全部名称，并恢复同名内置选择。
